# Crimson Canvas

IMPORTANT IMPLEMENTATION INSTRUCTION:

Before writing the final code, first establish the visual system and page architecture internally.

Do not immediately generate a generic landing page.

The first screen must be visually striking enough to function as an event campaign poster.

Prioritize art direction over information density.

Every major section should feel visually different while remaining part of the same red/black world.

The website should look like it was designed by an award-winning digital art studio, not generated from a standard website template.

Use the uploaded reference images as the primary visual moodboard.

When a suitable visual is not available, create abstract visual compositions using gradients, masks, SVG shapes, textures and CSS rather than inserting generic stock images.
